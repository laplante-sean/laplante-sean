I'm a software engineer, security researcher, open-source contributor, and hobby game developer.

## 🚧 What I'm Working On

- 🔭 Building indie games with Godot on [itch.io](https://troystorygames.itch.io/), including work on a larger project with friends at [Troy Story Games](https://troystorygames.com)
- 🧠 Contributing to [IntroVirt](https://github.com/IntroVirt/IntroVirt), a KVM guest introspection framework, and [kvm-introvirt](https://github.com/IntroVirt/kvm-introvirt)
- 🏴‍☠️ Designing CTF and security/educational challenges: [DOG-CTF](https://github.com/laplante-sean/dog-ctf), [Pred-CTF](https://github.com/laplante-sean/pred-ctf), [spaceflight](https://github.com/laplante-sean/spaceflight)
- 🛠️ Tinkering with hardware hacking, reverse engineering, and whatever else is interesting.

## ⭐ Featured Work

### 🛡️ Open Source & Security

- [IntroVirt](https://github.com/IntroVirt/IntroVirt): core contributor to a C++ virtual machine introspection library for KVM. Recent work includes modern Linux kernel support, memory breakpoint tracking fixes, Python bindings, and architectural documentation.
- [kvm-introvirt](https://github.com/IntroVirt/kvm-introvirt): KVM module work supporting IntroVirt's guest introspection capabilities.
- [DOG-CTF](https://github.com/laplante-sean/dog-ctf): Contributed a few CTF challenges for the 2026 UAlbany cyber competition.
- [Pred-CTF](https://github.com/laplante-sean/pred-ctf): Contributed a few CTF challenges for the Spring 2026 Cornell cyber club's CTF.
- [vulny](https://github.com/laplante-sean/vulny): a vulnerable Linux socket game for educational security practice.

### 🎮 Games & Experiments

- [Messenger Mouse](https://troystorygames.itch.io/messenger-mouse): A 2D action platformer in Godot, currently a work-in-progress with a playable demo on itch.
- [facelift](https://github.com/Troy-Story-Games/facelift): A Godot VR game submission for the 2026 Global Game Jam.
- [freeballz](https://github.com/laplante-sean/freeballz): a Godot ball-bouncing/block-breaking game.
- [Torn](https://github.com/laplante-sean/torn): a time-travel looper puzzle-platformer prototype built in Godot.
- [The Sun Is Off](https://github.com/laplante-sean/thesunisoff): a LOWREZJAM 2020 dungeon crawler experiment in tiny resolution constraints.
- [Motivation](https://github.com/laplante-sean/motivation): a Python smart-trainer project that disables your game controller when you stop pedaling hard enough.
- [Chevy Volt "Trip Mode"](https://github.com/laplante-sean/chevy-volt-trip-mode): A hardware/software/RE project that adds a "trip mode" to a 2017 Chevy bolt. ([blog post](https://seanlaplante.com/2021/11/13/hacking-my-chevy-volt-to-auto-switch-driving-modes-for-efficiency/))
